    Modelo de dados (estrela)

    Uma fato por fotografia com DataColeta, tags em formato longo para as páginas de distribuição, e fatos separadas para o histórico de saneamento.

    fRecursoSnapshot

    1 linha por recurso por coleta. SnapshotKey, ResourceIdKey (lower), SubscriptionId, RGKey, ResourceType, AMBIENTE, BU, CAPEX, CC, CCOWNER_Bruto, CLIENTE, PRODUTO, FOLIO, NoEscopo

    fTagValor

    Unpivot das 8 tags. SnapshotKey, ResourceIdKey, Tag, ValorBruto, ValorNorm, Status (Informado | Indefinido | Vazio)

    fSaneamento

    Histórico das ações. Acao (PRODUTO | BU_PAG_BANCOS), Onda, Granularidade, ChaveObjeto, ValorAntes, ValorDepois, Status, TambemNaOnda2

    dSnapshot

    SnapshotKey, DataColeta, Universo (Escopo | Completo)

    dSubscription

    SubscriptionId, Nome, ManagementGroup, NoEscopo

    dResourceGroup

    RGKey = SubscriptionId|lower(RG), Nome, SubscriptionId

    dCCOwnerDePara

    De, Para, Regra, Confianca, ValidadoPor, ValidadoEm

    dBUCC_Oficial

    CC, BU_Oficial, VigenciaInicio · pendente de envio

    fPolicyCompliance

    DataColeta, Iniciativa, EhTag, Compliant, Total

    Relacionamentos 1:N: dSnapshot, dSubscription e dResourceGroup → fRecursoSnapshot; fRecursoSnapshot → fTagValor por (SnapshotKey, ResourceIdKey); dCCOwnerDePara[De] → fRecursoSnapshot[CCOWNER_Bruto]; dBUCC_Oficial[CC] → fRecursoSnapshot[CC].
